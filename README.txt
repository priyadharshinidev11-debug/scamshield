SCAMSHIELD - HTML/CSS/JAVASCRIPT VERSION

Files:
- index.html: application structure
- style.css: responsive design and themes
- script.js: scan heuristics, history, education cards, settings

HOW TO RUN:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. No npm install, framework, backend, database, or build step is needed.

FEATURES:
- Message and URL scanning interface
- Pattern-based warning detection
- Scan result explanation and warning indicators
- Dashboard statistics and recent activity
- Local scan history with filters and clear option
- Security education cards with category filters
- Light/dark theme
- Responsive desktop and mobile layout

IMPORTANT LIMITATION:
This is a frontend-only demo. It does not use AI, Google Safe Browsing, VirusTotal, a server, or a live threat intelligence database. Message and URL checks are simple JavaScript pattern checks performed in the browser. A result marked Safe is not a guarantee that content or a website is safe. Real reputation checks, AI analysis, account sync, SMS access, notifications, and browser-wide automatic scanning require external APIs, permissions, or a backend.
